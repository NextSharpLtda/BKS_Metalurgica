# BKS Metalúrgica

Site institucional estático exportado do projeto **BKS Metalúrgica Hero Section** no Google Stitch, com a identidade visual original e as imagens do pacote de exportação armazenadas localmente em `assets/images`.

## Executar localmente

Abra `index.html` diretamente ou rode um servidor estático:

```bash
npx serve .
```

## Publicar no GitHub Pages

1. Envie estes arquivos para a raiz do repositório.
2. Em **Settings → Pages**, selecione **Deploy from a branch**.
3. Escolha a branch principal e a pasta `/ (root)`.

Não há etapa de build nem dependências locais. O Tailwind CSS e as fontes são carregados por CDN. O formulário abre o WhatsApp oficial com os dados preenchidos.
